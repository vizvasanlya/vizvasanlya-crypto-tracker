Track portfolio allocation, price alerts, asset performance, stablecoin reserves, and risk signals.

## Features

- **Portfolio Management** — Add and track crypto holdings with cost basis
- **Performance Metrics** — Real-time portfolio value, allocation, and P&L
- **Risk Signals** — Concentration risk and volatility indicators
- **Status Tracking** — Active, watch, sold, and alert states
- **Search & Filter** — Find assets by status, priority, or name
- **Analytics View** — Portfolio distribution and performance breakdown
- **Import / Export** — JSON-based portfolio portability

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Markup | HTML5 |
| Styling | CSS3 (Custom Properties, Grid, Flexbox) |
| Logic | Vanilla JavaScript (ES2022) |
| Storage | LocalStorage |
| Server | Python HTTP server (dev) |

## Getting Started

### Prerequisites

- Python 3.x (for dev server)
- Modern web browser

### Installation

```bash
git clone https://github.com/vizvasanlya/First.git
cd First/vizvasanlya-crypto-tracker
```

### Run

```bash
npm start
```

Open [http://localhost:5173](http://localhost:5173)

### Docker

```bash
docker compose up --build
```
